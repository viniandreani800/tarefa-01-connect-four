**Disciplina:** INE5201 / UFSC

## Sobre o Projeto
Implementação do clássico jogo **Connect Four** em Python utilizando a biblioteca gráfica `tkinter`. O projeto conta com a estrutura de tabuleiro 6x7, lógica de gravidade para a queda das peças, alternância de turnos entre dois jogadores e detecção automática de vitória (horizontal, vertical e diagonal).

## Tecnologias Utilizadas
* Python
* Tkinter (Interface Gráfica)
* Git & GitHub (Controle de Versão)

## Como Executar
1. Certifique-se de que você tem o Python instalado no seu computador.
2. Faça o download deste repositório ou baixe o projeto em formato ZIP.
3. Execute o arquivo principal no terminal:
   ```bash
   python main.py
